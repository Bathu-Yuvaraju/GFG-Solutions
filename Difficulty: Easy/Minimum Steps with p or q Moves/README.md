<h2><a href="https://www.geeksforgeeks.org/problems/minimum-steps1159/1">Minimum Steps with p or q Moves</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18.6667px;">You are standing at the bottom of a staircase with <strong>exactly n</strong> stairs. You can take steps of size <strong>p</strong> or <strong>q </strong>at a time, calculate the <strong>minimum</strong> number of steps required to reach exactly the n-th stair using only these step sizes.</span></p><p><span style="font-size: 18.6667px;">You can take any combination of steps of size p and q to achieve this.</span></p><p><span style="font-size: 18.6667px;">If it is not possible to reach exactly n stairs using any combination of steps of size p and q, return <strong>-1</strong>.</span></p><p dir="ltr"><span style="font-size: 14pt;"><strong>Examples:</strong></span></p><pre><span style="font-size: 18.6667px;"><strong>Input: </strong>n = 15, p = 2, q = 3<strong>
Output: </strong>5<strong>
Explanation:</strong> The 15th stair can be reached using five moves of size 3: 3 + 3 + 3 + 3 + 3 = 15.
Hence, the minimum number of moves required is 5.</span></pre><pre><span style="font-size: 18.6667px;"><strong>Input: </strong>n = 19, p = 4, q = 3<strong>
Output: </strong>5<strong>
Explanation: </strong>One optimal sequence of moves is: 4 + 4 + 4 + 4 + 3 = 19
Thus, the 19th stair can be reached in 5 moves.</span></pre></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Arrays</code>&nbsp;<code>Dynamic Programming</code>&nbsp;
