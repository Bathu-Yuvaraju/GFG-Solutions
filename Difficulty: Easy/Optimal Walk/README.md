<h2><a href="https://www.geeksforgeeks.org/problems/optimal-walk3752/1">Optimal Walk</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given a point <strong>(n, 0)</strong> on the x-axis, you are standing at the origin <strong>(0, 0)</strong> and can move only on the x-axis. </span><span style="font-size: 18px;">If you are currently at <strong>(x, 0)</strong>, in one operation you can:</span></p><ul><li><span style="font-size: 18px;">Move one step forward to (x + 1, 0) with cost a.</span></li><li><span style="font-size: 18px;">Move one step backward to (x - 1, 0) with cost a.</span></li><li><span style="font-size: 18px;">Jump to (2 * x, 0) with cost b.</span></li></ul><p><span style="font-size: 18px;">Find the minimum cost required to reach <strong>(n, 0)</strong> from <strong>(0, 0)</strong>.</span></p><p><strong><span style="font-size: 18px;">Examples:</span></strong></p><pre><span style="font-size: 18px;"><strong>Input: </strong>n = 7, a = 1, b = 100<strong>
Output: </strong>7<strong>
Explanation: </strong>The minimum cost is obtained by moving forward one unit at each step. Total cost = 7 * 1 = 7.</span></pre><pre><span style="font-size: 18px;"><strong>Input: </strong>n = 8, a = 2, b = 4<strong>
Output: </strong>12<strong>
Explanation: </strong>One optimal path is 0 -&gt; 1 -&gt; 2 -&gt; 3 -&gt; 4 -&gt; 8. Total cost = 2 + 2 + 2 + 2 + 4 = 12.</span></pre></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Dynamic Programming</code>&nbsp;
